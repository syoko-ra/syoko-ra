現場の不便や手間を、仕組みで減らすことに取り組んでいます。東京電機大学大学院 理工学研究科 情報学専攻の修士1年です（2028年3月修了予定）。

### していること

- **店の業務の仕組みづくり**：埼玉県加須市のコミュニティカフェとコワーキングスペースで働きながら、予約・シフト・勤怠などの仕組みを作っています。
- **研究**：声に出さずに心の中で思い浮かべた母音を、脳波から読み取るBCI（脳とコンピューターをつなぐ技術）を研究しています。分類モデルの設計・実装・評価を担当しています。

### 公開しているもの

- [booth-notify](https://github.com/syoko-ra/booth-notify) — コワーキングの個室ブースの予約を、電話・メールからWeb予約へ置き換えた仕組み（Google Apps Script・Slack通知・館内モニター）。公開から約1か月半で、延べ40時間分（80枠）の予約を受け付けました（2026年9月14日集計）。
- [in-light.jp](https://in-light.jp) — カフェとコワーキングの公式サイト。制作と運用を担当しています（AWS・GitHub Actionsで公開）。
- [LPA線スペクトルとConformerを用いた想起音声中の母音認識](https://www.jstage.jst.go.jp/article/pjsai/JSAI2026/0/JSAI2026_3YinA34/_article/-char/ja) — 人工知能学会全国大会（JSAI2026）での発表、2026年6月。

店のシフト・勤怠・在庫などの仕組みは、スタッフの名前や実際のデータを含むため公開していません。

### 作り方

現場の困りごとをつかみ、何をどう解決するかを決め、使う人とすり合わせて運用するところを自分で担当しています。設計・実装・テストの多くは生成AI（Claude Code）と進めています。

### 技術・資格

Python（研究・PyTorch）／JavaScript・Google Apps Script／AWS（S3・CloudFront）・GitHub Actions／基本情報技術者（2023年10月取得）
